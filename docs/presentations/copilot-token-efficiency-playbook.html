The 6 levers, ranked by impact

Where the money actually goes

Pull these top to bottom. The first two — model choice and context scope — move the bill more than the rest combined. Everything here is Copilot-native, not generic advice.

1

Match the model to the task

The dominant lever. A frugal model can cost ~10–20× less per token for the same routine work. Prefer auto-selection — it routes by task and discounts the rate. Never run a reasoning model on a rename.

Impact
2

Scope the context

Input tokens are billed every request. Attach specific files with #file / #selection instead of @workspace for narrow tasks — and start a fresh chat per task, since long threads re-bill stale context on every turn.

Impact
3

Pick the cheapest sufficient mode

Cost climbs completions → ask → edit → agent. Completions are free; agent loops re-send context and tools each turn and quietly become the largest single line item. Reserve agent for genuinely multi-step work.

Impact
4

Cut output verbosity

Output tokens bill too. A standing “be concise, prefer diffs over full-file rewrites” instruction trims every future response. Set it once in copilot-instructions.md.

Impact
5

Reuse, don't re-type

Stop paying to re-establish context. *.instructions.md (with applyTo globs) and *.prompt.md load standing rules and recurring prompts automatically instead of re-sending them by hand.

Impact
6

Make code review deliberate

Automated Copilot code review spends credits and GitHub Actions minutes per run. Scope it to meaningful PRs and paths rather than firing on every push.

Impact

Levers 4 & 5 · ship these Monday

Three files that pay for themselves

Drop these in any repo. They load automatically, so the whole team stops paying to re-establish conventions and context in every thread.

.github/copilot-instructions.md

Repo-wide standing rules

“Lead with the answer. Prefer diffs over full-file rewrites. Be terse for experts.” Applies to every chat, edit, and agent request.

cuts output tokens
.github/instructions/*.instructions.md

Path-specific rules

Frontmatter applyTo: "**/*.test.*" targets a glob. Matching files stack (union, no override) — keep each one small.

scopes context
.github/prompts/*.prompt.md

Reusable prompts

A saved review checklist or scaffold. Invoke it instead of re-typing — and re-paying for — a long prompt every time.

reuse, don't re-type

Don't save credits by getting it wrong

Cheaper-but-wrong is the most expensive outcome — it costs a second request, a bad merge, or an outage. Compression never touches these:

exact paths & commands error strings identifiers & versions security warnings material risks validation status the actual answer

Priority when cost conflicts with quality: safety → correctness → user intent → validation → credit savings.

Prove it, don't assume it

Track AI Credit usage in GitHub billing before and after — org cost centers and budgets land on Business / Enterprise. A-B one real task (verbose baseline vs. this config, same model) and score quality 1–5 separately; adopt only if quality holds.

Plan credits (monthly, as of Jun 2026): Pro $10 · Pro+ $39 · Business $19/user · Enterprise $39/user. Free = completions only.
