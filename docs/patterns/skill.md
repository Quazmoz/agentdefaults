# Skill Pattern

## Purpose

Provide a reusable structure for new skill files.

## When To Use

Use when adding a composable behavior or task module under `skills/`.

## Inputs Needed

- Task type
- Required context
- Constraints
- Validation target

## Instructions

1. State the behavior clearly.
2. Define when to apply it.
3. Define inputs needed.
4. Include compact output expectations.
5. Add quality checks.

## Expected Output

A focused skill file that can be combined with an agent profile.

## Quality Bar

- Modular.
- Reusable.
- Compact.
- Validation-aware.
