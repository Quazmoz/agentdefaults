# Handoff Example

## Purpose

Show how to create compact continuation notes for long-running agent work.

## Files To Use

```text
agents/token-economy-orchestrator.md
skills/context-budgeting-and-pruning.md
skills/token-output-budgeting.md
```

## Prompt

```text
Create a compact handoff using Goal / State / Next. Preserve exact paths, commands, decisions, blockers, and validation status. Remove narrative filler.
```

## Expected Output

```text
Goal: target outcome
State: current facts and completed work
Next: precise continuation steps
```
