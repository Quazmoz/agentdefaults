# Compression Example

## Purpose

Show how to compress reusable prompts, memories, or instruction files.

## Files To Use

```text
skills/prompt-and-memory-compression.md
skills/token-efficiency-measurement.md
prompts/token-efficiency/compress-memory-file.md
```

## Prompt

```text
Compress this instruction file while preserving exact identifiers, safety boundaries, validation requirements, and user-specific constraints. Return the compressed version plus a short audit of what changed.
```

## Expected Output

```text
Compressed file: concise replacement text
Audit: preserved / removed / risks
```
